# Gomel EV (Android / Galaxy Z Fold)

Нативное Android-приложение (Kotlin + Jetpack Compose + Material 3 Expressive) для подбора электромобилей, сравнения дилеров Гомеля и расчёта автокредитов по ПДН.

- **[Страница релиза и список изменений](https://github.com/yras1090510/gomel-ev-app/releases/latest)**

## Что нового в v2.0.0

- **Адаптивная навигация Material 3:** в развёрнутом режиме Fold меню слева центрировано по вертикали (`NavigationRail`), на узком внешнем экране панель перенесена вниз (`NavigationBar`).
- **Адаптивная вёрстка без обрезаний (`FlowRow`):** номера телефонов дилеров, фильтры и кнопки корректно переносятся на любую ширину экрана.
- **15 уникальных иллюстраций автомобилей** с градиентным освещением и узнаваемыми силуэтами (включая `Geely EX2 Max`, `BYD Yuan UP`, `JAC E30X` б/у).
- **Тёмная и светлая темы** (`Авто / Светлая / Тёмная`), весенние переходы Material 3 Expressive и обновлённая адаптивная иконка (включая monochrome).
- База из **15 моделей авто**, **21 дилера Гомеля** и **45 кредитных / лизинговых линий** банков РБ с живой синхронизацией курса НБ РБ и сайтов дилеров/Myfin.
