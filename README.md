# Gomel EV (Android / Galaxy Fold)

Нативное Android-приложение (Kotlin + Jetpack Compose + Material 3 Adaptive) для подбора электромобилей и кредитных программ в Гомеле и Беларуси.

- **[Страница релиза и список изменений](https://github.com/yras1090510/gomel-ev-app/releases/latest)**

## Возможности

- Адаптивный дизайн под **Samsung Galaxy Z Fold** и складные экраны (`NavigationSuiteScaffold`, `FoldingFeature` Two-Pane).
- База из **15 моделей авто**, **21 дилера Гомеля** и **45 кредитных / лизинговых линий** банков РБ.
- Калькулятор ПДН (40% от дохода с вычетом текущих кредитов), расчёт минимального первоначального взноса и симулятор накоплений до сентября 2027.
- Автообновление курса USD НБРБ, ставок банков/Myfin и проверка новых сборок через `manifest.json`.
